UN DÍA, UNA VIRTUD — SAMSUNG

Esta versión incluye los 150 pasajes del documento Word facilitado. Son traducciones libres con referencias bibliográficas, aún pendientes de cotejo editorial. Las frases rotan cada día y vuelven a empezar tras la 150.

SUBIR A GITHUB DESDE SAMSUNG:
1. Descomprime este ZIP desde Mis archivos.
2. En Chrome abre tu repositorio de GitHub y usa Add file > Upload files.
3. Sube TODOS los archivos extraídos a la raíz, sustituyendo los que ya existan (no subas el ZIP).
4. Pulsa Commit changes. GitHub Pages publicará la actualización.
5. Abre la URL de tu app con Internet para cargar la nueva versión. Si no cambia, cierra la app, borra los datos del sitio desde Chrome o espera la activación del nuevo service worker y recarga.
6. Tras la primera carga correcta podrás leer sin conexión. Compruébalo en modo avión.

NOTA: Si cambias los datos del sitio se borran nombre y favoritos locales.
